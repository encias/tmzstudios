04 — Studio system

A studio that runs on its own AI agents.

Behind the work is Hermes, an agent operating system I built for the studio. It runs on Claude and local models, and takes on the repeatable parts of production so the design time goes where it matters.

  1. 01

    Research and brief

    Agents collect references, brand material and venue information, then turn them into a structured brief with sources.

  2. 02

    Visual exploration

    Early mood and concept variations are generated and compared quickly, before any 3D modelling starts.

  3. 03

    Production tracking

    Render queues, revisions and deliveries are tracked by the system, with every decision and file kept as evidence.

  4. 04

    Code and tools

    The same agents write the studio’s own tools: this website, presentation pages and production automations.

Agents speed up the work. Concept, space and light are still decided by a designer.
